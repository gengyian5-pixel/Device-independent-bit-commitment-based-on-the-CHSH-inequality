# 10. 附录 A–C（以及如何处理附录 D）

附录 D 已经作为第 9 章的引理使用过了。这里你要重构三种*协议*变体。

## 10.1 附录 A——PR 盒比特承诺

### 为什么需要这个附录

有两种相反的直觉：

- 不诚实参与方获得更强的关联 $\Rightarrow$ 安全性更差。
- 诚实参与方重新获得伪心灵感应（pseudo-telepathy）$\Rightarrow$ 可以采用 GHZ 风格的“用同一个测量进行测试和检查”，无需顺序 CHSH，安全性或许更好。

你将得到 $P_{\mathrm{gain}}\le 3/4$（保持不变，仍然仅基于无信号条件（no-signalling, NS））和 $P_{\mathrm{cont}}\le 3/4$（有所改善，而且现在是平衡的）。

**不要**假设 PR 盒是可信硬件（那会变成 Buhrman *et al.* 2006 的设定；如果不诚实参与方无法篡改硬件，该工作可以实现*完美*比特承诺（bit commitment, BC））。这里 Alice 可以制备任意无信号盒。

### 协议（请自行写出）

Alice 持有盒 0，Bob 持有盒 1。各有两个输入和两个输出。诚实的 PR 关联为 $r^0\oplus r^1=s^0 s^1$。

1. **承诺。** Alice 输入 $s^0=b$，采样掩码 $a$，并发送 $q=r^0\oplus a s^0$。
2. **揭示。** Alice 发送 $s^0,r^0$。Bob 检查令牌（$q=r^0$ 或 $q=r^0\oplus s^0$）。然后，他均匀随机选择 $s^1$ 并检查 PR 方程。任一检查失败即中止。

**练习 10.1。** 为什么不再需要顺序测试？因为 PR 方程*必然*成立。一个随机的 $s^1$ 可以同时测试盒子并检查所揭示的 $(s^0,r^0)$ 是否一致。GHZ 技巧就此恢复。

### Alice 的安全性

**练习 10.2。** 使用输入 $\{0,1\}$ 而非 $\{2,3\}$ 重复 §4 的推导。得到相同的 NS 界 $P_{\mathrm{gain}}\le 3/4$。

**练习 10.3。** 饱和策略：假设 $q=r^0$，输入 $s^1=1$，猜测 $g=r^0\oplus r^1$。检查三种情况 $(s^0,a)=(0,\ast),(1,0),(1,1)$。你应恰好得到 $3/4$。

### Bob 的安全性

Alice 可以制备任意 NS 盒，甚至可以在决定 $q$ 之后才制备（她发送 $q$ 前没有接收任何信息）。重新标记 $q\to q\oplus 1$、$r^0\to r^0\oplus 1$ 是一种对称变换，因此可令 $q=0$。

**练习 10.4。** 如果她揭示 $0$，则必须发送 $r^0=0$。随后 Bob 对随机的 $s^1$ 检查 $r^1=0$。成功概率为 $\frac12[P(r^1=0\mid s^1=0)+P(r^1=0\mid s^1=1)]$。

如果她揭示 $1$，则 $r^0$ 的两个取值都被允许；Bob 检查 PR 方程。写出该概率，将两种揭示各以 $1/2$ 的权重相加，并得到论文的式 (21)。

**练习 10.5。** 仅使用 NS 条件和正性，证明式 (21) $\le 3/4$。然后给出饱和策略：Bob 的盒是经典的，且对两个 $s^1$ 都有 $P(r^1=0\mid s^1)=1$。

### 如何在 §6 / 附录 A 中讨论这一点

“超量子结构（supra-quantum structure）可以带来更高的安全性”这一论断指的是：$P_{\mathrm{cont}}$ 从 $0.85$ 降至 $0.75$，协议变得平衡，而且不再需要 $N\to\infty$。$P_{\mathrm{gain}}$ 并未变差。

## 10.2 附录 B——自由揭示时间，更差的 $P_{\mathrm{cont}}$

### 修改之处

Bob 仍然进行 $n$ 轮 CHSH 测试，仍然发送盒 $c$。**但是**，在时刻 $t_{n+1}$，他在 Alice 揭示*之前*就已经向保留的盒输入一个随机比特 $d$（事实上，只要是在 $t_{n+1}$，他甚至可以在 Alice 承诺之前这样做）。Alice 可以在之后任意时刻揭示。仅当 $d$ 恰好等于所揭示的 $b$ 时，Bob 才执行相等性检查。

**练习 10.6。** 使用硬币 $c,d$ 写出三个阶段。验证 $t_{i+1}-t_i$ 不再需要容纳 Alice 的往返通信：Bob 按照时钟测量保留的盒，与 Alice 无关。时间间隔可以任意短。

### 安全性

**练习 10.7。** Alice 的安全性（$P_{\mathrm{gain}}$）保持不变。

**练习 10.8。** 对 Bob 的安全性：以 $1/2$ 的概率有 $d\neq b$，此时 Bob 跳过最后一次测试，因此只要某种揭示满足*经典*令牌检查，他就会接受。不诚实的 Alice 随后可以揭示任一比特（令牌 $q=r\oplus ab$ 的设计本来就允许用两种方式揭示）。以 $1/2$ 的概率有 $d=b$，此时情况与原协议相同。由此得出

$$
P_{\mathrm{cont}}\;\longmapsto\;\frac12\bigl(P_{\mathrm{cont}}+1\bigr).
$$

其渐近值为 $\frac12(\cos^2(\pi/8)+1)\simeq 0.927$。在你的笔记中写明这个数值；论文仅保留了函数形式。

## 10.3 附录 C——大型实验室：自由揭示时间，相同的 $P_{\mathrm{cont}}$

### 资源

$N+1$ *对*盒子，并且各对之间彼此隔离（不仅每一对中的两个盒子相互隔离，不同盒对之间也相互隔离）。这并不实用；它是一个存在性论证。

### 协议（请自行写出）

1. Bob 私下选取 $n\in\{1,\dots,N+1\}$ 和硬币 $c$，发送第 $n$ 对中的盒 $c$。
2. Alice 像通常一样在该盒上作出承诺。
3. Alice 在自己选择的时刻揭示。
4. Bob *并行地*对**所有其他盒对**进行 CHSH 测试，同时以输入 $b$ 测量第 $n$ 对中保留的盒。如果相等性检查失败，或在被测试的 $N$ 对盒子上得到的 CHSH 平均值低于 $I_{\mathrm{th}}$，则中止。

**练习 10.9。** 为什么自由揭示时间不会让保留的盒“知道”自己很特殊？因为 CHSH 测试是在*其他*盒对上进行的，而且对第 $n$ 对的检查测量与这些测试同时进行——不存在这样一种额外的延迟测量：在某个盒已经经历 $n$ 轮 CHSH 后再对它测量。

### 归约到顺序界

无需重新证明 Azuma 不等式。通过以下两项松弛来论证，其中每一项都只可能*帮助* Alice：

1. 仅使用第 $1,\dots,n-1$ 对盒估计 CHSH（Alice 知道编号）。这对 Bob 更不利，因此 $P_{\mathrm{cont}}$ 不会减小。
2. 让第 $k$ 对中的每个盒都拥有同一侧此前所有盒子的完整记忆。这就重现了一个顺序记忆过程。对 Bob 而言，这同样更加不利。

于是，$P_{\mathrm{cont}}$ 至多等于原顺序协议中的相应值。由于测试同时进行，时序问题不复存在。

**练习 10.10。** 用三段文字写出这一比较论证。它就是附录 C 的全部安全性证明。

## 10.4 附录中*不应*包含什么

- 不要在附录 B/C 中重新推导 §4，只需用一句话说明“保持不变”。
- 不要为附录 C 推导新的有限-$N$ 收敛速率；论文明确拒绝这样做。
- 不要声称附录 B 的时间间隔既可以很短，$P_{\mathrm{cont}}$ 又仍保持为 $\cos^2(\pi/8)$。那是附录 C 实现的效果。
