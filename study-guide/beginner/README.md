# 零基础路径（不需要量子力学）

如果你**没有学过量子力学**，不要从第 1 节的公式开始。按下面顺序读完「白话篇」，你就能讲清楚这篇论文在干什么、谁在防谁、两个关键数字从哪来。读完后再去碰原来的英文技术章节。

| 顺序 | 文件 | 你读完应能说出 |
|---|---|---|
| 1 | [从零开始：比特、概率、黑盒子](01-from-zero.zh.md) | 盒子是什么、什么叫“不能传信” |
| 2 | [CHSH：一场不许商量的游戏](02-chsh-game.zh.md) | 为什么 2、2.828、4 这三个数重要 |
| 3 | [比特承诺：先封存、后打开](03-bit-commitment.zh.md) | Alice / Bob 各想骗什么 |
| 4 | [协议故事：闹钟、抽签、寄盒子](04-protocol.zh.md) | 三步在干什么、为什么要藏 $n$ |
| 5 | [谁在作弊：两个数字的含义](05-cheating.zh.md) | $3/4$ 和 $\cos^2(\pi/8)$ 是什么意思 |
| 6 | [附录白话，以及下一步](06-variants-and-next.zh.md) | 三种改法；如何进入技术章节 |

英文短导读（同一套直觉）：[00-no-quantum.md](../00-no-quantum.md)。

技术章节仍从 [00-how-to-use.md](../00-how-to-use.md) 开始。白话篇**不代替**证明，只保证你进门时知道每件兵器是干什么的。
