# 零基础路径（不需要量子力学）

如果你**没有学过量子力学**，不要从第 1 节的公式开始。这里按“直觉 → 例子 → 公式 → 证明地图”分成四层。前六章讲论文故事；第七章逐符号过桥；第八章用练习检验是否真的懂。

## 怎么学

每次只读一章，随后合上文件回答本章检查点。第 2、4、5 章中的表格请亲手重抄一次。遇到术语先查 [术语表](glossary.zh.md)，不要立即搜索完整量子力学教材。

| 顺序 | 文件 | 你读完应能说出 |
|---|---|---|
| 1 | [从零开始：比特、概率、黑盒子](01-from-zero.zh.md) | 盒子是什么、什么叫“不能传信” |
| 2 | [CHSH：一场不许商量的游戏](02-chsh-game.zh.md) | 为什么 2、2.828、4 这三个数重要 |
| 3 | [比特承诺：先封存、后打开](03-bit-commitment.zh.md) | Alice / Bob 各想骗什么 |

随时查：[中英术语与符号表](glossary.zh.md)。

## 三档目标

- **只想理解论文主张：**读 1–6。
- **想读懂原论文公式：**读完 1–7，再读中文版预备知识。
- **想自己重建证明：**完成第 8 章，再进入技术学习指南第 7–9 章。
